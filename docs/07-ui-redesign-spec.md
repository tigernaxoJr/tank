## 一、設計原則

1. **手機橫放優先**（基準 844×390），直放與桌機是同一套元件的延伸，不是另一套。
2. **戰場優先**：戰鬥時 UI 只占四個角落與上緣，畫面中央 ≥ 70% 留給戰場。
3. **拇指區**：左拇指管移動，右拇指管瞄準與開火，其餘放邊緣。
4. **一屏一件事**：每個畫面一個主要動作，主按鈕最大且固定在右下。
5. **用圖不用字**：數值改用儀表、圖示、環形進度；文字只留名稱與少數標籤。
6. **最小觸控目標 44 px**（CSS px），主要按鈕 ≥ 64 px；所有 HUD 預留 `env(safe-area-inset-*)`（瀏海、圓角）。
7. **美術**：保留「天空 × 戰爭 × 歡樂」亮色卡通（主色湛藍、陽光金、暖橘、亮白，**嚴禁濁青色**），元件全部重畫、描邊改細（約 2 px 等效）、大量留白；墨色 `#1d2340`。

## 二、三個畫面

### 1. 進入遊戲（標題場景）

```
[指揮官牌]                              [設定][?]
        TANK ARTILLERY（Logo）
   主角坦克站在草地上（點它換車）      ┌ 快速開戰（最大，金色）┐
                                      │ 房間      │ 單機練習  │
```

* 整個畫面是一個場景（沿用現有地圖視差圖層當背景），**沒有卡片**。
* 主角坦克即選車入口：點擊彈出橫向輪播（隨機車也在輪播內）。
* 三個入口集中右下：快速開戰（加入/建立房間的捷徑）、房間（房號輸入 + 房間列表抽屜）、單機練習。
* 指揮官牌左上：頭像（目前坦克）+ 名稱輸入；設定、作戰手冊在右上。
* 直放：Logo 上、坦克中、按鈕堆疊在下。

### 2. 遊戲房間

```
[‹ 房號 ABCD ⧉]                                  [連線/準備狀態]
 戰車展示台 │ 兩隊 5 席圓形座位環（對峙） │ 地圖票券 + 大「準備 / 開打」
```

* 左：戰車展示台，左右滑換車；耐久 / 火力 / 機動用**環形圖**；兩種砲彈用兩個槽（`chip_slot`）。
* 中：橘隊、藍隊各一排圓形座位環（空位顯示 ＋、有人、準備、房主皇冠），中間 VS；點空位入座，房主可在空位加電腦。
* 右：地圖做成票券，點開橫向圖庫（取代下拉與彈窗）；斷線處置收進票券下的設定圖示。
* 主按鈕（準備 / 開打）釘在右下，與標題場景同位置，肌肉記憶一致。
* 直放：底部三分頁（戰車 / 隊伍 / 地圖），主按鈕浮在分頁上方。

### 3. 戰鬥 HUD

```
[暫停][音效] ─ 橘隊血條 ─ ⏱15 ─ 藍隊血條 ─ [風向羅盤][雷達圖示]
                     戰 場（完全空出）
 [◀][▶] 燃料環         [砲彈1][砲彈2]       ┌ 發射環 ┐
 [仰角刻度盤 + ▲▼]                          └按住蓄力┘
```

* **發射環**：按住時環形力道表填滿（取代橫向力道條）；放開發射；等待回合時變灰。
* **仰角**：左側刻度盤 + ▲▼ 鈕；鍵盤方向鍵與 Space 沿用。
* 移動：左下 ◀ ▶，旁邊燃料環。
* 砲彈切換：發射環上方兩個 `chip_slot`，選中者高亮。
* 自己坦克的血量與狀態（中毒、冰凍、浸濕）標在**坦克頭上**（世界座標跟隨），不佔畫面。
* 雷達預設收成圖示，點開才展開浮層。
* 敵方回合：操作區淡出（不可按），只留上緣血條 + 計時 + 風向。
* 回合橫幅、結算畫面維持置中，但改用新 `banner_plate` 與緞帶元件。

## 四、素材生成規範（agy）

* 遵守 `docs/04-art-asset-pipeline.md` §八的 **agy 作業模式**：**Agent 不呼叫 agy**，只把 prompt 與格線規格寫成文件，由使用者叫 agy 去讀並執行；每張 sheet 只生一次；完成後由 Agent 指定存放路徑、使用者叫 agy 搬過去。
* agy 做完後由使用者告知，Agent 驗收成品（路徑、尺寸、洋紅邊）並回報；不合格由使用者決定是否重生。
* **prompt 文件只寫素材需求**，不得出現呼叫者身分或工具名稱（例如 Claude、Agent）；檔名、commit 訊息與文件只記錄素材本身（sheet 名稱、格線、驗收結果）。
* 一次一張 sheet；**先有完整 prompt 與格線規格**（`tools/assets/agy-ui/*.prompt.txt`）才交給使用者。
* 統一規格：洋紅 `#ff00ff` 純色底、每格獨立不相觸、**不含任何文字**（Logo 除外）、墨色細描邊 `#1d2340`、平塗 + 簡單手繪紋理、左上受光、硬陰影在下方、不使用濁青 / 灰色、不抄任何現有遊戲美術。
* 原圖放 `tools/assets/agy-ui/raw/<sheet>_raw.png`（供重切），切割後的成品放 `public/assets/ui2/`（尚未建立，切割腳本待寫）。
* 驗收：在白 / 深 / 灰三種背景上檢查洋紅邊；網格是否照規格排列；圖示風格是否一致。不合格由使用者決定是否重生。
