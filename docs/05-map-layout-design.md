# 地圖版型設計守則 (05-map-layout-design.md)

單純的正弦波地表太單調，因此地圖改為「基礎波形 + 版型特徵 (layout features)」兩層組合，
做出浮空島、吊橋、雙層薄地、階梯台地、不可破壞基岩等多層地形。

## 一、版權守則（必讀）

- 參考其他砲術遊戲（例如其他經典回合制砲術遊戲）時，**只能借用通用的「地形版型概念」**
  （浮空島、吊橋、雙層薄地、階梯台地、不可破壞地塊）。這類版型屬於遊戲玩法構想，不是可受著作權保護的表達。
- **禁止**複製對方的地圖圖片、背景、像素地形資料、音樂、角色或文字描述，也禁止在遊戲內（地圖名稱、描述、UI）
  使用對方的地圖名稱或商標字樣。地圖名稱與描述一律自行原創。
- 美術只能用 Kenney CC0 素材或專案原創的程式繪製美術（見 [04-art-asset-pipeline.md](./04-art-asset-pipeline.md)）。
- 「畫風」可以參考（例如坦克與砲彈走 Q 版可愛砲兵感），但每個造型都必須自行設計，規則見 04 §六。
- 參考資料（例如 namu.wiki 對 其他砲術遊戲地圖的文字介紹）只能放在本文件當作設計靈感出處，不得搬進程式碼或遊戲內文案。

## 二、地形資料模型

`TankCorePort` 的遮罩本來就是逐像素位圖，現在支援三種值：

| 值 | 意義 | 行為 |
|----|------|------|
| `0` AIR | 空氣 | — |
| `1` DIRT | 可破壞土壤 | `carveCircle` 會挖掉 |
| `2` BEDROCK | 不可破壞基岩 | `carveCircle` 跳過；渲染為石磚紋，不擺裝飾 |

`MapBlueprint.layout`（→ `TerrainWaveOptions`）：

- `baseMode: 'none'`：沒有地面，下方就是深淵（吊橋 / 懸谷類地圖）。
- `baseThickness`：只保留波形地表往下 N px（薄地表，下方是深淵）。
- `waveProfile.jitter`：地表隨機抖動上限（預設 18px）；平原類地圖要調小，否則振幅再小也會凹凸不平。
- `features[]`：依序疊加，座標全部是地圖寬高的比例 (0~1)：
  - `island`：平頂、底部半橢圓垂墜的浮空島
  - `bridge`：x0~x1 的薄板，`shape` 可為 `flat / arch / sag / w / wave`，`endThickness` 讓兩端加厚成橋墩
  - `ellipse` / `rect`：搭配 `op: 'add' | 'carve' | 'bedrock'`
- 用 `mirrored([...])` 左右鏡像，確保雙方陣營地形對等。
- 特徵生成不消耗 RNG，所以加上特徵不會改變既有地圖同一種子的基礎波形。

## 三、多層地形的物理規則

- **貼地一律「從坦克腳下往下找」**（`groundBelow` / `groundUnderTank`），不可用整欄最上層的 `surfaceY`，
  否則站在橋下或島下的坦克會被瞬移到上層。`surfaceY` 只用在出生點與裝飾擺放。
- **行走**（`walkAlongTerrain`，玩家、P2P 同步與電腦 AI 共用）：每水平 1px 最多爬升 3px（約 70°）；
  更陡的牆面、淨空不足 18px 的低矮天花板會擋住坦克；可以走下台階或橋緣，但不會自己走進深淵。
- **出生點**：取該欄最上層地表；若該欄是深淵，就往兩側找最近的地面（`findSpawnGround`）。
- 墜出地圖底部仍判定陣亡；這是懸空類地圖「打穿地面讓對手掉落」的核心玩法。
- 渲染時逐像素記錄「距離原始地形正上方空氣的深度」（`originalDepth`），讓浮島頂、橋面與下層薄地都畫上草皮 / 雪層。

### 重製方針（前三張地圖）

舊的前三張地圖用 Kenney 背景重新上色 + Kenney 地表磚 + 原創基岩，三種畫風混在一起，和原創主題落差太大，因此逐張改為原創主題重製（已完成：`harvest_plains`、`volcano_gorge`、`gale_coast`；舊 Kenney 地圖主題與其素材已刪除）。
**每一張都要先和使用者討論風格與內容再動工**，且配色 / 題材不得與其他地圖重複（已使用：黃昏沙漠、藍天浮島、極光冰夜、紫色月夜遺跡、晨光農場、火山熔岩、熱帶強風海岸）。

## 五、新增地圖流程

1. 在 `MapPresetId`（`src/shared/kernel/types.ts`）加入新 id。
2. 在 [`mapRegistry.ts`](../src/features/battle/domain/mapRegistry.ts) 新增 `MapBlueprint`：`theme` 指向 `THEME_REGISTRY` 中的主題；
   需要全新美術時在 `tools/assets/paint_map_themes.mjs` 新增主題並執行 `pnpm run paint:maps`。
3. 大廳縮圖由 `loadMapPreview`（`MapPreview.vue`）依版型即時繪製（主題天空、視差山丘、地表紋理、墨線與出生點旗），不需要另外準備 thumbnail。
4. 驗收：5v5 出生點都不在深淵、雙方地形對稱、坦克能在主要地面上左右移動、打穿薄層後會正確下墜。

## 六、Rust 核心與 TS 核心的地形一致性（已實作）

- `crates/tank-core`（Rust 版確定性核心）已移植 `layout` / BEDROCK / `groundBelow` / `jitter`，並以黃金檔逐項對照 TS 版；改了 TS 地形生成或行為後的重新產生流程見 [`02` §五](./02-architecture-and-subagent-guide.md)。
- 目前執行期仍只使用 TS 版 `DeterministicTankCore`；切換到 Wasm 前還需要轉接層（見 `todo.md`）。
